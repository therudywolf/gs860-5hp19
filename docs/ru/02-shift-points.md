# 02 · Точки переключения

## 1. Где

16 матриц 2D8 **8×11**, заголовок программы k по адресу `0x091B2 + k·0x70`, указатели — каталог `0x9B2C…0x9B68` (документ 01 §3).

```
заголовок : 0x091B2 + k·0x70          [00 08][00 0B]
ось X     : +4,  8 байт  = 1..8         (номер перехода)
ось Y     : +12, 11 байт = педаль 0..255 (своя у каждой матрицы!)
данные    : 0x091C9 + k·0x70 + строка·8 + столбец   (байт, км/ч)
```

Столбцы: `0 = 1→2, 1 = 2→3, 2 = 3→4, 3 = 4→5` (вверх), `4 = 2→1, 5 = 3→2, 6 = 4→3, 7 = 5→4` (вниз). Значение — **скорость в км/ч**, при которой переход разрешается; `250`/`255` — «никогда» (вверх), `0` — «не применяется».

Вход по педали — `[0xFFFF9182]` (0..255): в `0x290F6 / 0x29120 / 0x29146 / 0x291A8 / 0x291CC` матрицы опрашиваются как `d0 = столбец 1..8, d1 = [0xFFFF9182]`, интерполяция между строками линейная. Полный газ без кикдауна на референсной машине даёт ≈229, кикдаун-выключатель — строка 255.

Оси Y **не одинаковы** у разных программ (сток):

| Программы | Ось педали |
|---|---|
| 00, 01, 02, 06, 11, 14, 15 | 0, 46, 83, 121, 160, 198, 203, 243, 244, 254, 255 |
| 03, 04, 05, 07 | 0, 10, 46, 83, 121, 160, 198, 234, 244, 254, 255 |
| 08, 09, 10, 12 | 0, 33, 59, 84, 113, 141, 170, 205, 240, 254, 255 |
| 13 | 0, 46, 83, 121, 160, 188, 189, 243, 244, 254, 255 |

Оси не менять (см. документ 09); менять только данные.

## 3. Пересчёт км/ч ↔ об/мин

Передаточные числа зашиты в коде: `0x12F9C` (u16, ×1000) = **3.665 / 1.999 / 1.407 / 1.000 / 0.742**. Обороты выходного вала на 1 км/ч зависят от главной пары и колёс: на референсной машине (E39 2.5, стоковая главная пара) по логу **27.11 об/мин на км/ч**. Отсюда обороты турбины (≈ ДВС при замкнутом ГДТ) на 1 км/ч:

| Передача | i | об/мин на км/ч (27.11 × i) | принято в расчётах проекта |
|---|---|---|---|
| 1 | 3.665 | 99.4 | 99.6 |
| 2 | 1.999 | 54.2 | 54.3 |
| 3 | 1.407 | 38.1 | 38.3 |
| 4 | 1.000 | 27.1 | 27.1 |
| 5 | 0.742 | 20.1 | 20.1 |

(Разница между столбцами — измеренные 3.67/2.00/1.41 против зашитых.) Обороты в момент переключения вверх `g→g+1` = `v · k_g`; обороты после понижения `g+1→g` = `v · k_g`.

**Другая главная пара или размер колёс:** `k_g = i_g · FD · 1000 / (60 · L)`, где L — длина окружности колеса в метрах, FD — главная пара. Проще измерить: по кадру DS2 выходной вал = байт 2 × 32 об/мин (документ 06), поделить на скорость. Как именно блок получает «км/ч» для сравнения с матрицей (из n_вых через константу или из скоростей колёс по CAN) — по коду не установлено; в TCC-модуле скорость читается из `0xFFFF918F`.

## 4. Как считать точку под отсечку

Правила, по которым собирались все пресеты (проверяются `verify`-скриптами, не глазами):

1. **Вверх ниже искры.** `v · k_g ≤ n_искра − 150`. Иначе коробка не доезжает до точки и висит в отсечке. Какой из ограничителей ДВС срабатывает первым (искра или топливо) и на сколько ниже отсечки — зависит от блока ДВС; берите нижний из них.
2. **Вниз оставляет запас.** После понижения `v · k_g ≤ n_искра − 500`.
3. **Гистерезис.** В одной строке `вниз < вверх` для одной пары передач, иначе качели.
4. **Монотонность.** По столбцу значения не убывают с ростом педали; в строке порядок 1→2 < 2→3 < 3→4 < 4→5.
5. **Все строки.** Править все строки педали, не только верхние: в одной из ранних сборок были переписаны только строки 160…255, и на 16 % педали линия 3→2 прыгала с 28 на 78 км/ч, а кикдаун разрешал 3→2 до 100 км/ч (= 2-я на 5400 об/мин) при линии 2→3 = 112 км/ч — «кидает передачи и упирается в отсечку».

Пример: отсечка 6784, искра ≈6656, цель вверх в пол ≈6550 → `1→2 = 6550/99.6 = 66 км/ч`, `2→3 = 120`, `3→4 = 171`. Это значения пресета v18 (документ 08).

## 5. Ручные программы

В 08/09/10 столбцы вверх можно поставить 255 — блок сам вверх не переключится, и мотор упрётся в отсечку. **Столбцы вниз в строках 0…254 — заводская защита от раскрутки**, не поднимать: при `2→1 = 0` и `3→2 = 10` блок сам скидывает передачу только на почти остановке. В стоке кикдаун-строка ручных программ вниз `33 / 70 / 112 / 183`.

## 6. Челнок 4↔5 в D

В стоке 03/04/07: 4→5 = 64 км/ч, 5→4 = 56 (строки педали 0…46) — гистерезис 8 км/ч, 5-я включается на ≈1286 об/мин. В пресетах 4→5 поднят до 75 в строках 0/10/46 (гистерезис 19 км/ч, ≈1508 об/мин).

## 7. Связь с блокировкой ГДТ и снятием момента

Точки переключения — единственный «спортивный» рычаг, у которого есть отдельная ветка (матрицы выбираются по номеру программы `0xFFFF91B0`). Гидравлика (документ 04) и карты снятия момента (документ 04 §9) общие для всех программ.
