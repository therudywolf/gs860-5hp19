# Глоссарий

| Термин | Значение в этом репозитории |
|---|---|
| **GS8.60.0 / GS8.60.4** | поколения блока управления АКПП Bosch для ZF 5HP19 у BMW. GS8.60.0 — образ 256 КБ (программы 19C0/19D0 и др.), GS8.60.4 — 512 КБ (например 20C0), другая раскладка |
| **19C0 / 19D0** | метки ПО/калибровки в образе. У обоих исследованных дампов программа (код 0x10000–0x40000) помечена 19D0 и совпадает байт-в-байт; метка калибровки в хвосте окна (`0x0FFCE`) — `19C0 KA20` у стока E39 2.5 и `19D0 620P` у Alpina B3 |
| **Окно калибровки / Partial** | область `0x8000–0x10000` образа; в виде отдельного 32 КБ файла адреса = адрес − 0x8000 |
| **Сток** | стоковая калибровка, относительно которой сделаны рецепты (метка `19C0KA20`) |
| **Рецепт** | JSON-diff сток → тюн: адреса, оси, старые и новые данные; оси не меняются (документ 08) |
| **Ветка 0 / ветка 1** | два набора параметров выбора передачи и ГДТ, флаг `0xFFFF91CB` (документ 01 §4). В ранних заметках «обычная» / «злая» |
| **Программа (0…15)** | одна из 16 матриц точек переключения, номер в `0xFFFF91B0` |
| **Zug / Schub** | нем. «тяга» / «накат»: переключение под нагрузкой (класс 1) и без нагрузки (класс 0), флаг `0xFFFF9722` |
| **Hochschaltung / Rückschaltung** | повышение / понижение передачи |
| **kind (0…3)** | набор записей автомата исполнения: 0 Schub-Hoch, 1 Zug-Hoch, 2 Schub-Rück, 3 Zug-Rück; `0xFFFF971B` |
| **Тип перехода (1…8)** | индекс записи внутри набора: 1 N↔2, 2 1↔2, 3 2↔3, 4 3↔4, 5 4↔5, 6 3→1, 7 4→2, 8 5→3; `0xFFFF971A`, матрица `0x12FDC` |
| **Запись / поле fNN** | массив 32-битных указателей на калибровки одного перехода; поле fNN — указатель со смещением 4·NN |
| **Фаза** | шаг последовательности давления (`0xFFFF9735`), таблица `0x13034`: 1 пауза, 2 быстрое наполнение, 3 разделительный такт, 4 подвод, 9 открытое давление скольжения, 10 регулируемое скольжение, 11 дожим, 12 завершение понижения |
| **Schnellfüllung / время наполнения** | фаза 2: быстрое наполнение включаемого сцепления; время f10(ATF) + поправки, давление f13(ATF) |
| **Füllausgleich** | фаза 4: выравнивание/подвод к точке касания, длительность f27 |
| **Schleifdruck / давление скольжения** | давление включаемого сцепления в фазах 9–11 (kind1/kind3 f32), `0xFFFF9720` |
| **Überschneidung / перекрытие** | одновременная работа выключаемого и включаемого сцеплений при повышении; давление выключаемого — kind1 f53, `0xFFFF9783` |
| **Целевое время скольжения** | 3×3-таблицы (kind1 f45, kind3 f33/f69): сколько тактов по 10 мс должна занять фаза скольжения; регулятор 0x364A2 подбирает градиент давления |
| **Включаемое / выключаемое сцепление** | on-coming / off-going clutch: пакет, который набирает давление, и пакет, который отпускается |
| **EDS** | Elektronischer Drucksteller — пропорциональный соленоид давления (в 5HP19 несколько каналов; ГДТ — отдельный канал). Соответствие каналов ШИМ соленоидам в этой прошивке не доказано |
| **MV** | Magnetventil — дискретный соленоид переключения MV1…MV3; их картина по передачам — таблица `0x12E30` |
| **WÜK / TCC / ГДТ** | Wandlerüberbrückungskupplung — муфта блокировки гидротрансформатора. В GS8.60.0 — четырёхступенчатая лесенка управляющей величины (документ 03) |
| **Ступень ГДТ** | одна из 4 величин лесенки `0x888C` (32/96/160/224 в стоке); выбор — по педали и скорости |
| **Турбина** | обороты турбинного колеса ГДТ = входного вала коробки (`0xFFFF97B4`); при замкнутой муфте равны оборотам ДВС |
| **n_вых** | обороты выходного вала (`0xFFFF97B2`); на референсной машине 27.11 об/мин на км/ч |
| **Момент** | момент ДВС по CAN, Нм (`0xFFFF97A0`); ось Y карт = Нм/4 + 25 |
| **ATF** | масло АКПП; сырой байт датчика `0xFFFF8435`; в кадре °C = байт − 48 |
| **Термодерейт** | ограничение эффективной педали по температуре ATF (таблица `0x9A6E`, документ 05 §2) |
| **Снятие момента** | запрос к DME уменьшить момент на время переключения; карты `0xAB0C…0xAE40`, значение = % оставляемого момента |
| **Такт (10 мс)** | единица всех времён в таблицах исполнения переключения |
| **Кикдаун** | строка педали 255 матриц переключений — концевик полного нажатия |
| **Аварийный режим** | Notlauf: блок держит одну передачу, `0xFFFF9113 != 0`; в статусном кадре видно по байтам 12/14/17/18/20 |
| **DS2** | диагностический протокол BMW по K-line; у GS8.60.0 адрес 0x32, 9600 бод, чтение RAM командой 0x06 |
| **Сегмент 4** | в таблице сегментов DS2 `0x3E8A` — RAM `0xFF8000–0xFF9E00` |
| **XDF** | определение таблиц для TunerPro; `xdf/GS8600_19D0_Full256K.xdf` (256 КБ) и `xdf/GS8600_19x0_Partial32K.xdf` (32 КБ, адреса − 0x8000) |
| **Alpina (эталон)** | калибровка Alpina B3 3.3 E46 на том же ПО (19D0 620P); используется как заводской пример «быстрой» настройки, но её оси не копируются |
