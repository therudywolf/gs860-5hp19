# Глоссарий

| Термин | Значение в этом репозитории |
|---|---|
| **GS8.60.0 / GS8.60.4** | поколения блока управления АКПП Bosch для ZF 5HP19 у BMW. GS8.60.0 — образ 256 КБ (программы 19C0/19D0 и др.), GS8.60.4 — 512 КБ (например 20C0), другая раскладка |
| **19C0 / 19D0** | метки ПО/калибровки в образе. У обоих исследованных дампов программа (код 0x10000–0x40000) помечена 19D0 и совпадает байт-в-байт; метка калибровки в хвосте окна (`0x0FFCE`) — `19C0 KA20` у стока E39 2.5 и `19D0 620P` у Alpina B3 |
| **Окно калибровки / Partial** | область `0x8000–0x10000` образа; в виде отдельного 32 КБ файла адреса = адрес − 0x8000 |
| **Сток** | стоковая калибровка, относительно которой сделаны рецепты (метка `19C0KA20`) |
| **Рецепт** | JSON-diff сток → тюн: адреса, оси, старые и новые данные; оси не меняются (документ 08) |
| **Ветка 0 / ветка 1** | D / S. Переключает признак S `0xFFFF91CB` (документ 01 §4): 1 в кулисе до нажатия +/-. Ветку читают функции AGS и таблица 0x81A0, к ГДТ и гидравлике она не относится. M это отдельный признак `0xFFFF91F3`. В ранних заметках «обычная» / «злая» |
| **Программа (P0…PF)** | одна из 16 программ переключения, активная хранится в `0xFFFF91A0`. Матрицу для неё выбирает таблица в функции 0x24BA4: P0 = k14, P1 = k6, P2 = k11, P3 = k15, P4 = k0, P5 = k1, P6 = k2, P7 = k13, P8 = k9, P9 = k12, PA = k5, PB = k10, PC = k7, PD = k8, PE = k4, PF = k3. `0xFFFF91B0` это принудительная программа (0 / 4 / 5), документ 01 §5 |
| **Zug / Schub** | нем. «тяга» / «накат»: переключение под нагрузкой (класс 1) и без нагрузки (класс 0), флаг `0xFFFF9722` |
| **Hochschaltung / Rückschaltung** | повышение / понижение передачи |
| **kind (0…3)** | набор записей автомата исполнения: 0 Schub-Hoch, 1 Zug-Hoch, 2 Schub-Rück, 3 Zug-Rück; `0xFFFF971B` |
| **Тип перехода (1…8)** | индекс записи внутри набора из матрицы `0x12FDC`[из-1][в-1] (`0xFFFF971A`). Вид 1: 2 1-2, 3 2-3, 4 3-4, 5 4-5, 6 3-1, 7 4-2, 8 5-3, подтверждено. Вид 2 (проверено кодом 25.09.2026): 0 это 1 в 6, 1 это 2 в 6, 2 это 2 в 1, 3 это 3 в 2. Код передачи 6 не нейтраль, а 1-я с дополнительным элементом (0x12D31), прежняя подпись «N-2» неверна (документ 04 §2) |
| **Запись / поле fNN** | массив 32-битных указателей на калибровки одного перехода; поле fNN — указатель со смещением 4·NN |
| **Фаза** | шаг последовательности давления (`0xFFFF9735`), таблица `0x13034`: 1 пауза, 2 быстрое наполнение, 3 разделительный такт, 4 подвод, 9 открытое давление скольжения, 10 регулируемое скольжение, 11 дожим, 12 завершение понижения |
| **Schnellfüllung / время наполнения** | фаза 2: быстрое наполнение включаемого сцепления; время f10(ATF) + поправки, давление f13(ATF) |
| **Füllausgleich** | фаза 4: выравнивание/подвод к точке касания, длительность f27 |
| **Schleifdruck / давление скольжения** | давление включаемого сцепления в фазах 9–11 (kind1/kind3 f32), `0xFFFF9720` |
| **Überschneidung / перекрытие** | одновременная работа выключаемого и включаемого сцеплений при повышении; давление выключаемого — kind1 f53, `0xFFFF9783` |
| **Целевое время скольжения** | 3×3-таблицы (kind1 f45, kind3 f33/f69): сколько тактов по 10 мс должна занять фаза скольжения; регулятор 0x364A2 подбирает градиент давления |
| **Включаемое / выключаемое сцепление** | on-coming / off-going clutch: пакет, который набирает давление, и пакет, который отпускается |
| **EDS** | Elektronischer Drucksteller, пропорциональный соленоид давления (в 5HP19 несколько каналов, у муфты ГДТ свой). Для муфты ГДТ ШИМ `0xFFFF95BA` уходит на выход `0xFFFFFF34` (сторонний реверс, принят 23.09.2026). Для остальных каналов соответствие ШИМ соленоидам не доказано |
| **MV** | Magnetventil — дискретный соленоид переключения MV1…MV3; их картина по передачам — таблица `0x12E30` |
| **WÜK / TCC / ГДТ** | Wandlerüberbrückungskupplung, муфта блокировки гидротрансформатора. Верхний уровень 0x29056 раз в 10 мс считает запрос `0xFFFF91F9`: 0 разомкнута, 1 регулируемое скольжение, 2 замкнута (пороги 0x993A, группы 0x897E). Нижний автомат 0x32B08 / 0x33F66 (состояния 0-8) ведёт ШИМ `0xFFFF95BA` до 0x1F40 (документ 03) |
| **Ступень ГДТ** | устаревший термин этого репозитория. «Лесенка» `0x888C` (32/96/160/224 в стоке) это «домашние» очки уровней AGS, а не ступени муфты (документ 03 §7). У муфты есть запрос 0 / 1 / 2 и состояния 0-8 |
| **Турбина** | обороты турбинного колеса ГДТ = входного вала коробки (`0xFFFF97B4`); при замкнутой муфте равны оборотам ДВС |
| **n_вых** | обороты выходного вала (`0xFFFF97B2`), на референсной машине 27.11 об/мин на км/ч. Матрицы переключения, оси скорости таблиц AGS и пороги блокировки ГДТ 0x993A хранят n_вых / 32 (`0xFFFF918F`), документ 02 §3 |
| **Момент** | `0xFFFF97A0`: момент турбины, Нм, 97A4 × 97F4 / 100 (0x2DFBA). Ось Y карт `0xFFFF97DF` = 97A0/4 + 25 |
| **ATF** | масло АКПП; сырой байт датчика `0xFFFF8435`; в кадре °C = байт − 48 |
| **Термодерейт** | ограничение эффективной педали по температуре ATF (таблица `0x9A6E`, документ 05 §2) |
| **Снятие момента** | запрос к DME уменьшить момент на время переключения. Один канал: байт 3 кадра EGS1, `0xFFFF90C0` из `0xFFFF918D` = max(`0xFFFF958D`, `0xFFFF97E1`), 958D пишет только 0x2E3C6 (документ 04 §9). Карты `0xAB0C…0xAE40` это опорное скольжение регулятора ГДТ, а не снятие момента |
| **Такт (10 мс)** | единица всех времён в таблицах исполнения переключения |
| **Кикдаун** | строка педали 255 матриц переключений, концевик полного нажатия. Признак кикдауна `0xFFFF9113`: при нём ручная ветка выключена (документ 02 §5) |
| **Аварийный режим** | Notlauf: 4-я передача, регуляторы давления выключены. Признак `0xFFFF90C1`, его ставит 0x222A2 по биту 3 слова масок `0xFFFF8FA2`. В кадре 0B 03 это бит 0 байта 18, заметно также по байтам 12/14/17/20. `0xFFFF9113` это кикдаун, а не аварийный режим (документ 05 §3, §6) |
| **DS2** | диагностический протокол BMW по K-line; у GS8.60.0 адрес 0x32, 9600 бод, чтение RAM командой 0x06 |
| **Сегмент 4** | в таблице сегментов DS2 `0x3E8A` — RAM `0xFF8000–0xFF9E00` |
| **XDF** | определение таблиц для TunerPro; `xdf/GS8600_19D0_Full256K.xdf` (256 КБ) и `xdf/GS8600_19x0_Partial32K.xdf` (32 КБ, адреса − 0x8000) |
| **Alpina (эталон)** | калибровка Alpina B3 3.3 E46 на том же ПО (19D0 620P); используется как заводской пример «быстрой» настройки, но её оси не копируются |
| **AGS** | адаптивный выбор программы: очки `0xFFFF9216` (0..255) определяют уровень 1-4, уровень выбирает программу (D: P0 / P1, S: P2 / P3). Функции 0x1DEBC, 0x1Fxxx, таблицы 0x901E-0x915E, параметры 0x888C-0x88C1. До 23.09.2026 этот репозиторий ошибочно описывал AGS как блокировку ГДТ (документ 03 §7) |
| **Признак S / признак M** | `0xFFFF91CB` = 1 в кулисе до нажатия +/- (S), `0xFFFF91F3` = 1 после нажатия +/- при коде программы 0x0B / 0x0D (M), документ 01 §4 |
| **Ступень 0xFFFF90CD** | 1 / 2 / 3 включает программы P4 / P5 / P6 (матрицы k0 / k1 / k2) с приоритетом выше D и S. Что это горные ступени, гипотеза, не доказано |
| **Минимальная передача** | таблица `0x8AE2 + 5 × программа` (0x1E442, `0xFFFF91B4`, арбитр 0x236C8): не даёт ручному понижению посадить мотор выше порога, сама передачу не повышает (документ 02 §5) |
| **Монитор турбины** | 0x26C84, задача 50 мс: турбина `0xFFFF8DE2` не ниже [0x8B44] (сток 6720) около секунды даёт ошибку 0x25 и аварийный режим (документ 05 §6) |
| **EGS1 / DME1 / DME2** | кадры CAN. EGS1 (0x43F) шлёт коробка: байт 0 биты 0-2 целевая передача, байт 3 снятие момента. Из DME1 коробка берёт обороты мотора, из DME2 тормоз (байт 6 бит 0, `0xFFFF97F5`). Педаль приходит CAN-байтом `0xFFFF8439`, по-видимому это байт 5 DME2 (вывод, не проверено). Байт 2 DME2 штатно не читается (документ 04 §15) |
