# 12 · GS8.60.0 (19D0) и GS8.60.4 (20C0): чем отличаются

Сводка различий двух программ одной коробки ZF 5HP19 (блок Bosch GS8.60). Подробности с адресами инструкций: документы 01–10 (GS8.60.0, ПО 19C0 и 19D0, 256 КБ) и документ 11 (GS8.60.4, ПО 20C0, 512 КБ). Здесь только то, что в них доказано, с теми же уровнями уверенности. Непроверенное так и названо.

## Выводы

1. Это разные программы с разной раскладкой памяти. Ни один адрес, слот каталога или адрес RAM 19D0 к 20C0 не переносится. Общие у них формат таблиц, единица матриц переключения, алгоритм контрольных сумм и набор команд DS2.
2. Логика выбора передачи та же: 16 матриц, единица обороты выходного вала / 32, выбор матрицы по номеру программы. Из 890 функций 19D0 для 763 найдена пара в 20C0, часть совпадает инструкция в инструкцию.
3. Главные отличия 20C0 по поведению:
   1. блокировка ГДТ разрешена для кодов передач 1–6 и проверяется второй раз, по оборотам турбины.
   2. к порогу повышения добавляется прибавка.
   3. есть запрос повышения по оборотам мотора.
   4. в левой кулисе сразу включается M.
   5. порог монитора турбины 7232 об/мин вместо 6720.
   6. восемь наборов записей автомата переключения вместо одного.
4. Пресеты `recipes/` и документы 02–09 к 20C0 не применяются. После любой правки 20C0 пересчитать три суммы: `tools/gs860_crc.py fix`.

## 1. Образ и контрольные суммы

| | 19D0 (GS8.60.0) | 20C0 (GS8.60.4) |
|---|---|---|
| размер образа | 256 КБ | 512 КБ |
| метка программы | `0x4322` | `B223K_0520C0` в `0x6FF7C` |
| метка калибровки | `0xFFCE` | `B223K_0520C06440` в `0x7FFCE` |
| загрузчик, сумма | `0x00000–0x042FF`, сумма в `0x5FFE` | `0x00000–0x043FF`, сумма в `0x5FFE` |
| программа, сумма | `0x10000–0x3F77B`, сумма в `0x3F7FE` | `0x08000–0x6FF7B`, сумма в `0x6FFFE` |
| калибровка, сумма | `0x08000–0x0FFCD`, одна зона, сумма в `0xFFFE` | `0x70000–0x7FFCD`, зоны `0x70000–0x71BC0` и `0x78000–0x7D858`, сумма в `0x7FFFE` |
| константы ПЗУ программы | `0x10000–0x14FFF` | `0x08000–0x0FFFF` |
| код | `0x15000–0x3A997` | `0x10000–0x258D3` и `0x40000–0x55E4D` |
| записи автомата переключения | `0x3A998–0x3CEFF` | `0x55E4E–0x5953F` |
| алгоритм сумм | CRC-16/XMODEM, таблица `0x3EDA` | CRC-16/XMODEM, таблица `0x3EE2` (та же), функция `0x223C` |
| когда блок считает суммы | только по запросу тестера (DS2 `0x0A`) | так же |

У 20C0 константы ПЗУ (`0x08000–0x0FFFF`: передаточные числа, типы переходов, арбитр) входят в сумму программы, а не калибровки. Документ 01 и документ 11 §1, §2.

## 2. Калибровка и каталог указателей

| | 19D0 | 20C0 |
|---|---|---|
| формат таблицы | `[u16 nx][u16 ny][ось X][ось Y][данные]`, big-endian, оси растут | тот же |
| каталог указателей таблиц | `0x9ADC`, 48 слотов | `0x71BC2`, 43 слота |
| слоты 19D0 0–5 | в каталоге | в каталоге нет, код читает те же таблицы напрямую (`0x7013A`, `0x70196`, `0x701A8`, `0x70210`, `0x70236`, `0x70EF8`) |
| слот 36 | нет | `0x71AD0`, пороги блокировки ГДТ групп 11–12 |
| датчик ATF, мВ в сырую температуру | `0x9A82` | `0x71B66`, та же кривая |
| термодерейт по ATF | `0x9A6E`, `0x9A78` | `0x71B52`, `0x71B5C`, те же данные |

Документ 11 §3, §8.

## 3. Матрицы точек переключения и передачи

| | 19D0 | 20C0 |
|---|---|---|
| матрицы | 16 таблиц 2D8 8×11 | 16 таблиц 2D8 8×11 в `0x7120E + k × 0x70`, k = 0…15 |
| оси | | равны 19D0 во всех 16 парах, данные равны у k9, k12, k13 |
| единица | обороты выходного вала / 32 (`0x24F5E lsr.w #5`) | так же (`0x20D36 lsr.w #5`) |
| функция скорости | `0x24E82` | `0x20C5A`, инструкция в инструкцию |
| повышение | значение `≥` порога матрицы (`0x24AC8`) | значение `≥` порога матрицы плюс прибавка `[0xFFFF9143]` (`0x2061E`), прибавка из `0x70B98` при `[0xFFFF91B3] = 2` (`0x20D8E`) |
| понижение | `0x24ADE` | `0x206A2`, так же |
| выбор матрицы по программе | `0x24BA4` | `0x20768`, та же таблица программа и матрица |
| матрица k7 | выбирается программой PC | кодом не выбирается: записи PC ссылаются на программу 6 (матрица k2) |
| передаточные числа | `0x12F9C[передача − 1]`, читается в 24 местах | `0x0E0D2[код передачи]` = 3665, 3665, 1999, 1407, 1000, 742, 742, 4096, читает одна функция `0x41648` |
| передачи 1–5 | 3,665 / 1,999 / 1,407 / 1,000 / 0,742 | те же числа |
| код передачи 6 | 1-я с дополнительным элементом, передаточное 1-й (документ 04 §2) | запись 6 побайтно равна записи 1, в таблице передаточных у кода 6 стоит 742, назначение не установлено |
| записи передач на программу | | 6 (коды 1–6) |

Роли матриц по программам для 19D0 описаны в документе 02, для 20C0 это гипотеза (документ 11 §5). Документ 11 §4.

## 4. Блокировка ГДТ, верхний уровень

| | 19D0 | 20C0 |
|---|---|---|
| функция | `0x29056` | `0x2547E` |
| маска передач, где блокировка разрешена | `0x8978` = `0x003C`, передачи 2–5 | `0x7096E` = `0x007E`, коды передач 1–6 |
| проверка по выходному валу | группа `0x897E`, пороги `0x993A` 30×7 против n_вых / 32 | `0x255F2`, группа `0x70970`, пороги `0x71996` 30×9 и `0x71AD0` 6×9 |
| проверка по турбине | нет | `0x257C2`, пороги `0x70BB2` против турбины / 32 `0xFFFF9145` |
| сведение двух проверок | нет | таблица ПЗУ `0x0AF1E` 3×3 |

Нижний уровень (автомат муфты, ШИМ) у 20C0 не разбирался. Документ 03 и документ 11 §6.

## 5. AGS, кулиса, арбитр запросов передачи

| | 19D0 | 20C0 |
|---|---|---|
| функция AGS | `0x1DEBC` | `0x19084` |
| «домашние» очки уровней 1–4 | `0x888C` = 32 / 96 / 160 / 224 | `0x7089C` = 32 / 75 / 160 / 224 |
| верхние границы очков | `0x8878`, `0x8879` | не найдены |
| левая кулиса до нажатия +/− | ветка S (`[0x8975]` = `0xFE`), M по нажатию | сразу код M `0x0B` (`0x70966`), ветка S осталась только при `[0xFFFF918C] = 2` |
| арбитр запросов передачи | `0x236C8`, 25 записей | `0x1F200`, 26 записей |
| запрос повышения по оборотам мотора | нет | `0x105DE`, запись 5 арбитра, работает при `[0xFFFF9066] ≤ 40` |

Документ 03 §7 и документ 11 §7.

## 6. Защиты

| | 19D0 | 20C0 |
|---|---|---|
| монитор турбины, ошибка `0x25` | `0x26C84`, порог `0x8B44` = 6720 об/мин турбины | `0x23086` (инструкция в инструкцию), порог `0x70BA8` = 7232 |
| монитор напряжения | `0x265F4`, скаляр `0x8EE8` = 9000 мВ, `0x8EEA` = 7000 мВ | `0x2287E`, таблица `0x70F32` вместо скаляра 9000, `0x70F40` = 7000 мВ, `0x70F46` = 1500 мВ |
| функции без пары в 20C0 | `0x26AD6` (ошибка `0x21`), `0x33024` (сброс муфты по оборотам и тормозу) | |

Константы 7000 у обеих программ это милливольты бортсети, а не обороты (документ 05 §1). Документ 05 и документ 11 §8.

## 7. Записи автомата переключения

| | 19D0 | 20C0 |
|---|---|---|
| наборы записей | один, корень `0xFFFF94F8`, четыре вида | восемь наборов с корнями `0xFFFF9820…983C`, всего 20 корней `0xFFFF9800–0xFFFF984C` |
| таблица типов переходов | `0x12FDC`, 7×7 `[из − 1][в − 1]` | `0x0E092`, 8×8 `[из][в]` по кодам передач |
| тип 1 | 2 и 6 в обе стороны | 0 и 2, 5 и 6 в обе стороны |
| типы 2–8 | 1 и 2, 2 и 3, 3 и 4, 4 и 5 в обе стороны, из 3 в 1, из 4 в 2, из 5 в 3 | те же |

Документ 04 §2 и документ 11 §9.

## 8. DS2 и CAN

| | 19D0 | 20C0 |
|---|---|---|
| команды DS2 | 17, диспетчер `0x10E58` | те же 17 в том же порядке, диспетчер `0x12F76` |
| кадр `0B 03` | 24 байта | 33 байта: байты 24–32 это три счётчика `0xFFFF99F4`, `99F8`, `99FC`, смысл не установлен |
| адреса RAM в кадре | документ 06 | другие, например обороты ДВС / 32 `0xFFFF9140` (в 19D0 `0xFFFF9197`) |
| таблица объектов CAN | `0x10D08`, записи по 18 байт | `0x08E30`, записи по 20 байт |
| объекты CAN только в 20C0 | | передача `0x43B`, приём `0x1F8`, `0x338`, `0x545` |

Документ 06 и документ 11 §10, §11.

## 9. Что совпадает инструкция в инструкцию

Скорость (`0x20C5A`), понижение (`0x206A2`), арбитраж программ (`0x1EC1C` и `0x1ED3C`, в 19D0 `0x23110` и `0x23230`), монитор турбины (`0x23086`), удержание после переключения (`0x4A712`), `lookup − 128` (`0x5248E`). Адреса 20C0, пары в 19D0 в документе 11 §12. Всего сопоставлено 763 функции 19D0 из 890 (25.09.2026).
