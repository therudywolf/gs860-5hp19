# 09 · Что не трогать и почему

Список запретов. Каждый пункт стоил кому-то неездовой коробки, аварийного режима или недели поиска.

## 1. Вне окна калибровки

| Что | Почему |
|---|---|
| `0x0000–0x8000` | загрузчик, идентификация, драйвер DS2. Без этого блок не прошить обратно |
| `0x10000–0x40000` | код и дескрипторы записей. Любая правка = патч кода; в репозитории таких патчей нет и хуков не публикуется |
| хвост `0x0FFCE–0x10000` | метка калибровки и 2 байта неизвестного назначения (документ 07 §6) |

`apply_recipe.py` физически не может писать вне `0x8000–0x10000`.

## 2. Оси таблиц — никогда

Оси всех таблиц (`X`, `Y`) в рецептах не меняются. Причина — документ 04 §11: сборка, где 118 таблицам записали оси другой калибровки с экстраполированными данными, дала удары на 2→3 / 3→4, провалы оборотов на понижении и случайное поведение по температуре. Код читает ячейку по осям; смещённая ось = смещённая физика во всех фазах сразу, и по логу это не отделить от «просто плохих данных». Копировать чужую таблицу целиком можно только если её оси **побайтно** совпадают со стоком (пример — `0xB90E` Alpina).

## 3. Гидравлика (документ 04 §12)

| Поле / адреса | Что это | Почему не трогать |
|---|---|---|
| kind1 f10: `D6C2 / D6E2, D722, D782, D7E2` | время быстрого наполнения по ATF | недолив = задержка и хлопок; перелив = удар в начале фазы 4. Alpina не трогает |
| kind1 f13: `D01E / D03E, D07E, D0DE, D13E` | давление быстрого наполнения | то же |
| kind1 f27: `E091 … E09A`, f43: `D670 … D698` | длительности фаз 4 и 9 | сокращение = удар в начале скольжения; Alpina делает фазу 9 **длиннее** |
| kind1 f15 / f29 / f41 / f42, `A2C6 …` | поправки по ATF, холодные поправки | правятся только по замерам на холодной коробке |
| kind1 f23 / f24: `DF05 … DF14`, `DEC4 … DED3`; f47 `DED8 / DED9` | мин / макс давления | f24 — предохранитель от удара; «поднять максимум, чтобы регулятор не упирался» = перенести удар в сцепление |
| kind1 f70: `B40E, B42A, B4AE, B532, B5B6` (4×4); kind3 f65: `B446 … B5D2` (6×6) | семантика по коду не доказана | Alpina меняет их в ×0.3–7 с другими осями — тем более не копировать |
| f11 (`D538`), адаптации в RAM | адаптация времени наполнения | после прошивки — Reset Adaptation, не «подправить константой» |
| `C206, C90C, C1FA …` | 1D-таблицы 5×1 / 4×1 полей f38 / f39 (нули) | не структуры; копировать в них байты «вслепую» бессмысленно |
| kind3 f45 `BA78` вверх | давление выключаемого на 4→3 | поднимать — медленнее отпускает; в v10/v18 стоит ×1.15 и это ошибка направления |

Также: строки малого момента (Y ≤ 58, ≤ 132 Нм) карт давления — комфорт в городе; менять только Y ≥ 82.

## 4. Выбор передачи и ГДТ

| Что | Почему |
|---|---|
| `0x8214 = 4` | число ступеней ГДТ — размер цикла в коде |
| `0x8D92 / 0x8D78 / 0x8975`, `0x88F2 + k` | выбор ветки калибровки и атрибуты программ: бит 2 в `0x88F2` **не** включает ветку 1 (пишет 5 в `0xFFFF90C2`, назначение неизвестно) — уже наступали |
| пороги ГДТ 1-й передачи `0x901E / 0x903E` | замыкание на 1-й — вибрации и нагрев, выигрыша нет |
| столбцы вниз ручных программ 08/09/10 в строках 0…254 | защита от раскрутки |
| матрица сброса ветки 0 `0x889C` | размыкание в D на сбросе газа — заводское поведение, к которому привыкли все |
| `0x81A0 / 0x81B2` | порог модуля выбора передачи по оборотам ДВС/32 (документ 05 §4); смысл сравнения — гипотеза. Не «фазы» |
| `0xA066 … 0xA20A` (слоты 13–15) | назначение не расшифровано |

## 5. Скаляры диагностики

| Что | Почему |
|---|---|
| `0x8EE0–0x8F0E`, в т. ч. `0x8EE8 / 0x8EEA / 0x8EF0`, `0x8EFC`, `0x8F00`, `0x8F08 / 0x8F0A` | пороги напряжений в мВ (документ 03 §5, 05 §1). Это не температура и не обороты турбины (доказано по записи переменных в 0x20D78). В v17 0x8EEA был ошибочно поднят до 7300, в v18 возвращён. Правка ничего полезного не даёт и может отключить/включить диагностику питания |

## 6. Метод

- Не выдавать интерполяцию «раз константа 7000 — значит обороты» за факт без ссылки из кода **и** записи переменной (документ 10).
- Не совмещать в одной сборке шаги, которые потом нельзя разделить по логу (документ 10 §5).
- Не шить без сравнения SHA-256 собранного файла с журналом сборки и без Reset Adaptation после.
- Не выкладывать полные дампы (документ 07 §5).
